# local-seo

## Purpose
Apply basic SEO and technical metadata best practices to landing pages.

## Meta Tags
Always include:
- <title> — under 60 characters, includes primary keyword
- <meta name="description"> — 140 to 160 characters, includes keywords, clear benefit
- <meta property="og:title"> — same as or variant of page title
- <meta property="og:description"> — same as or variant of meta description
- <meta property="og:type" content="website">
- <meta property="og:url"> — canonical URL if known
- <meta property="og:image"> — 1200x630px image if available
- <meta name="twitter:card" content="summary_large_image">
- <meta name="viewport" content="width=device-width, initial-scale=1">
- <meta charset="UTF-8">
- <link rel="canonical"> — if URL is known
- <html lang="en">

## Heading Structure
- One H1 per page — the primary headline
- H2 for main section headers
- H3 for sub-sections or card titles
- Do not skip heading levels
- Headings must be descriptive and include relevant terms naturally

## Semantic HTML
- Use <main>, <header>, <footer>, <nav>, <section>, <article>, <aside>
- Use <ul> and <li> for lists of items
- Use <time> for dates if present
- Use <address> for contact details if present

## Image SEO
- All meaningful images must have descriptive alt text
- Decorative images use alt=""
- Use descriptive file names where possible

## Page Speed Signals
- Preconnect to external font sources
- Use font-display: swap for custom fonts
- Defer non-critical scripts
- Do not block rendering with large CSS files

## Local SEO (if applicable)
- Include city/region in title if targeting local market
- Add schema markup for LocalBusiness if relevant
- NAP (Name, Address, Phone) must be consistent

## Application
Apply this skill to the <head> section and semantic HTML structure of every page built.
