# Skill: Website Art Director
## Project context
Single-file landing page: `index.html`. Dark background (`#0A0A0A`), gold accent (`#D4A017`), two fonts: Cormorant Garamond (serif, headings) and DM Sans (sans, body). All CSS is in a single `<style>` block inside the HTML file. No external stylesheet. No framework.

The design system is already strong. The risk is not that it looks bad — it is that it still looks like a template. The job is to identify where the execution is weak, inconsistent, or unfinished, and fix those specific points without redesigning what is already working.

## When to use
Run this skill when:
- The page feels visually like a dark-mode agency template rather than a specific studio
- Spacing between sections feels identical regardless of content relationship
- The founder portrait is still a CSS shimmer placeholder (this is a Critical failure)
- Any section uses the same layout rhythm as every other section
- The portfolio/work section needs visual weight commensurate with the trust it is supposed to build

## Goal
The page should feel like it was made by someone with taste, not generated by a tool that knows design rules. Every visual decision should feel considered. Inconsistency and placeholder states must be eliminated before launch.

## Strict rules
- The founder portrait placeholder (CSS shimmer + "Photo coming" badge) is a Critical launch blocker — flag it every time this skill runs
- The `<section id="services">` has `display:none` — this dead/duplicate section must be either removed or merged, never left hidden in the live DOM
- The inlined React tweaks-panel JavaScript (the Claude canvas editor artifact) must be removed from the production file — it adds ~200 lines of irrelevant code and references claudeusercontent.com URLs
- Font sizes must form the declared scale — check that body text does not drop below 15px on mobile
- Whitespace above a section heading must be greater than below (heading belongs to what follows)
- CTA buttons: minimum 12px vertical padding, 24px horizontal padding — verify the `.btn` rule enforces this
- Image contrast: the hero has no image — verify the gold orb + grid background creates sufficient visual interest without an image, or flag that a real photo is needed
- No section should feel visually identical to the one before it — vary layout width, density, or tone

## What to check
- **Founder portrait:** placeholder or real photo?
- **Hero:** does the visual atmosphere (orb, grid, grain) read as intentional or generic dark-mode template?
- **Services grid:** 2-column on desktop — does it feel balanced or cramped?
- **Work/portfolio section:** 5 concept cards — do they have enough visual weight to anchor trust?
- **Process steps:** 3-column — does the step number (large italic ghost number) read clearly or compete with the heading?
- **Mobile (375px):** does the type hierarchy survive? Do the hero CTAs stack without overlap?
- **Hidden section:** confirm `display:none` on `#services` — flag for removal
- **Tweaks panel code:** confirm it is present in the file — flag for removal

## Output format
**Element:** [section or component]
**Issue:** [what is wrong]
**Fix:** [specific instruction with values where possible]
**Priority:** Critical / High / Low

Group by: Typography · Spacing & Layout · Imagery · Cleanup (dead code / placeholders). End with the one visual change that would have the highest impact on perceived credibility.
