# Lumus Agency

> *We light the way.*

Official website of **Lumus Agency** — a creative agency based in Galway, Ireland.
The name comes from the Latin *lumus* — *light*.

Services: **Branding · Web Design · Social Media · Motion Graphics**

---

## Brand

| Token | Value |
| --- | --- |
| `--black` | `#0A0A0A` |
| `--dark` | `#111111` |
| `--gold` | `#D4A017` |
| `--gold-bright` | `#E8B420` |
| `--gold-pale` | `#f0c84a` |
| `--white` | `#FFFFFF` |
| `--text-muted` | `rgba(255,255,255,0.55)` |
| `--border-gold` | `rgba(212,160,23,0.25)` |

**Fonts** — Cormorant Garamond (display) · DM Sans (body/UI), both loaded via `next/font/google`.

**Design principles**
1. Darkness as Canvas
2. Gold as Signal
3. Generous Space
4. Serif for Soul
5. Motion with Purpose
6. Precision in Detail

---

## Stack

- Next.js 14 (App Router) · TypeScript
- Tailwind CSS with brand tokens
- GSAP + ScrollTrigger (motion)
- `lucide-react` (icons)
- Deploy target: Vercel

---

## Development

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm run start        # run built app
npm run lint
```
