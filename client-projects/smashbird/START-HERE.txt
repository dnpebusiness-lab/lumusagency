SMASHBIRD — what is in this folder
==================================

LIVE SITE — deploys straight from this repo via Netlify on every push.

  index.html          the site
  content.js          every fact, price, address and line of copy. Edit here.
  img/                logo lockups, the bird silhouette, and real site photos
  fonts/              Barlow / Barlow Condensed, latin subset, self-hosted
  netlify.toml        build config
  _headers            security headers

READ FIRST
  HANDOVER.md         what is done, what is still needed, and why. Start here.
  README.md           project notes

NOTE ON OPENING index.html DIRECTLY
  Don't — double-clicking index.html shows the site without the bird and with
  fallback type, because browsers block CSS masks and web fonts over file://.
  Serve the folder instead:
      python3 -m http.server 8000
