# Skill: Landing Page

## What This Skill Does
Loads specialised knowledge for designing and building high-converting single-page or landing page websites. Applies when the goal is maximum conversion from a single focused page rather than a full multi-page site.

## When to Use
Activate when:
- Client needs a focused campaign page
- Client is launching a single offer or service
- Client needs a temporary or quick-turnaround page
- A single service business (e.g., window cleaner, mobile dog groomer) with one offer
- The brief reveals the site could be one powerful page instead of five average ones

## Agent That Uses It
UI Design Agent (Phase 5 + 6) + Copywriting Agent (Phase 4)

## SKILL INSTRUCTIONS

### LANDING PAGE FUNDAMENTALS

#### The Single-Page Conversion Model

A landing page has one job: convert the visitor. Everything on the page either helps or hurts conversion. Nothing is neutral.

The page structure must follow the visitor's psychological journey:

```
1. ATTENTION (Hero)           ← Get them to stop and read
2. INTEREST (Problem/Solution) ← Show you understand their situation
3. DESIRE (Proof/Benefits)    ← Make them want what you offer
4. ACTION (CTA)               ← Make it easy and low-risk to act
```

---

### THE LANDING PAGE STRUCTURE

**Section 1: Hero**
- H1: Specific benefit or outcome (not business name)
- Subheadline: Expand the promise, address the target situation
- CTA: Above the fold, specific, low-friction
- Supporting element: Photo, short video, trust badge
- Trust signal: Reviews count, years in business, or social proof snippet

**Section 2: The Problem / Situation**
- Describe the situation the visitor is in
- Show empathy and understanding (not sympathy)
- Lead naturally into the solution
- Keep this tight — 2–3 sentences or bullets

**Section 3: The Solution / What You Get**
- What happens when they work with you
- Outcomes, not features
- Use specific details (how long, how much, what exactly)

**Section 4: How It Works**
- 3 steps maximum
- Make it look easy
- Remove fear of the unknown

**Section 5: Social Proof**
- Real testimonials with names and context
- Specific outcomes mentioned in quotes
- Numbers if available ("47 customers this year", "4.9 stars from 86 reviews")

**Section 6: The Offer / What's Included**
- What they get specifically
- Price or price range (if appropriate)
- Friction reducer ("Free call first", "No obligation quote")

**Section 7: FAQ**
- Answer the 4–5 most common objections
- Each answer should push toward conversion
- Addresses: price, timing, trust, suitability

**Section 8: Final CTA**
- Repeat the primary CTA
- Add urgency if legitimate ("Available from next week")
- Final friction reducer

---

### LANDING PAGE COPY RULES

- Lead with outcome, not offer: "Get a clean car every week" not "We offer car washing services"
- Specificity always beats vagueness: "Done in 2 hours" beats "Quick turnaround"
- Headlines must carry the page alone: if someone only reads the headlines, they should understand the full offer
- Testimonials must be specific: "Fantastic service!" converts no one. "Jim fixed our boiler on Christmas Eve and had it running in 90 minutes" converts everyone.

---

### LANDING PAGE DESIGN RULES

- **No navigation** (or minimal navigation) — keep visitors on the page
- **CTA colour:** Most contrasting colour on the page — impossible to miss
- **Single column** on mobile — never two-column below 768px
- **Sticky CTA or contact info** on mobile (fixed bottom bar with phone number or CTA button)
- **Section alternation:** Alternate background colours subtly to create rhythm without complexity
- **Progress through the page:** Each section must create enough desire to scroll to the next

---

### LANDING PAGE TECHNICAL RULES

- Single HTML file if possible (no CMS needed for a pure landing page)
- Astro generates static HTML perfectly for this — ideal choice
- Page load time is critical: < 2 seconds on mobile
- Analytics event tracking: track CTA clicks, scroll depth, form submissions
- A/B testing ready: keep component structure clean for easy variation testing
