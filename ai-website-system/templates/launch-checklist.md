## PRE-LAUNCH GATES

### Gate 1: QA Complete
- [ ] QA Agent has issued GO status
- [ ] All critical bugs resolved
- [ ] All placeholder content removed
- [ ] All forms tested and working

### Gate 2: Content Complete
- [ ] All copy is final and approved
- [ ] All images are optimised and properly licensed
- [ ] All testimonials are real
- [ ] No blank sections anywhere

### Gate 3: SEO Complete
- [ ] All page title tags set and unique
- [ ] All meta descriptions set and unique
- [ ] OG tags set on all pages
- [ ] Schema markup implemented
- [ ] Images have descriptive alt text
- [ ] Sitemap.xml generated
- [ ] Robots.txt configured

### Gate 4: Technical Complete
- [ ] No console errors on any page
- [ ] PageSpeed ≥85 mobile / ≥90 desktop
- [ ] Core Web Vitals all green
- [ ] SSL active
- [ ] 301 redirects in place (if migrating)
- [ ] Cookie consent working
- [ ] Analytics installed (GA4)
- [ ] Google Search Console verified

### Gate 5: Client Approval
- [ ] Client has reviewed the staging site
- [ ] Client has explicitly approved the staging site
- [ ] All client-requested changes are applied

---

## DEPLOYMENT STEPS

- [ ] Final build deployed to production
- [ ] Custom domain configured
- [ ] SSL certificate active on production domain
- [ ] www redirect working (www → non-www or vice versa)
- [ ] HTTP → HTTPS redirect confirmed
- [ ] All pages loading on production domain
- [ ] All forms tested on production domain
- [ ] Analytics firing on production (check GA4 real-time)
- [ ] Search Console verified on production URL
- [ ] Sitemap submitted to Search Console

---

## POST-LAUNCH IMMEDIATE CHECKS (within 1 hour)

- [ ] Homepage loads correctly
- [ ] All navigation links work
- [ ] Contact form submits and delivers
- [ ] Phone link works on mobile
- [ ] Email link works
- [ ] Images loading correctly
- [ ] No 404 errors on key pages
- [ ] SSL padlock visible
- [ ] Analytics receiving data (GA4 real-time)

---

## CLIENT HANDOVER

- [ ] Client informed site is live
- [ ] Client given login credentials (hosting, CMS, analytics)
- [ ] Credentials stored securely and shared with client
- [ ] Handover documentation sent
- [ ] Maintenance plan discussed
- [ ] Client knows how to contact us for support
