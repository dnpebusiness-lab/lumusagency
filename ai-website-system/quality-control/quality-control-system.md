# Quality Control System

> This document defines the anti-generic, anti-template quality standards that every website built by Lumus Agency must meet. The Orchestrator Agent enforces these standards at every quality gate.

---

## THE CORE QUALITY PRINCIPLE

Every website must pass this test:

> **"Could this website, this copy, or this design belong to any other business in this category?"**

If the answer is YES — it fails. Revise until the answer is NO.

This single test eliminates:
- Generic copy ("passionate about...", "dedicated to excellence")
- Template design (same layout as every competitor)
- Vague positioning ("quality service for the whole family")
- Interchangeable photography choices (smiling stock people)
- Meaningless CTAs ("Get in touch", "Learn more")

## PHASE-BY-PHASE QUALITY GATES

### Phase 1: Client Brief

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Primary goal | Single sentence, specific measurable outcome | "To have a great website" |
| USPs | Specific, provable, not claimed by competitors | "Great quality and friendly service" |
| Target audience | Specific enough to recognise a real person | "Everyone" or "families" |
| Tone | Goes beyond generic adjectives | "Professional and friendly" alone |
| Missing info | All gaps documented as questions | Blank fields |

### Phase 2: Brand Strategy

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Positioning | Unique to this one business | Works for any competitor |
| Differentiator | Not claimable by competitors | "Family-run", "Great quality" |
| Tone examples | Concrete, show don't tell | "Warm" without demonstration |
| Key messages | What audience wants to hear | What client wants to say |
| Brand pillars | Practically expressed in content | Too abstract to apply |

### Phase 3: Sitemap & UX

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Page count | Only necessary pages | Bloated 12-page site for a café |
| Conversion path | 2 clicks max to primary action | Contact buried 3+ levels deep |
| Navigation | 6 items or fewer | 9+ nav items, cognitive overload |
| Mobile UX | Explicitly addressed | Just assumed "it's responsive" |
| Each page purpose | Specific stated reason | "The client wanted it" |

### Phase 4: Copywriting

| Check | Standard | Common Failure |
|-------|----------|---------------|
| No banned phrases | Zero instances | "Passionate about", "your journey" |
| Specificity | Real details, not generic claims | "Years of experience" |
| H1 per page | Communicates specific benefit | Just the business name |
| CTAs | Action + specific outcome | "Click here", "Learn more" |
| Tone match | Matches brand strategy exactly | Generic professional tone |
| Placeholders | Zero | "[Insert testimonial here]" |
| Anti-AI test | Sounds like a real person | Obvious AI-generated patterns |

### Phase 5–6: Design

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Colour specificity | All hex values given | "Warm earthy tones" |
| Typography specificity | Font name + full scale | "A nice serif font" |
| Visual hierarchy | Clear at every section | Everything the same visual weight |
| Mobile design | Explicitly designed | Just desktop made smaller |
| Design rationale | Every choice justified | Random aesthetic decisions |
| Competitor differentiation | Visually distinct | Same layout as every competitor |

### Phase 7: Development

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Copy accuracy | 100% matches approved doc | Small edits made by developer |
| Design fidelity | Matches visual direction | Developer made visual decisions |
| Accessibility | WCAG 2.1 AA minimum | Alt text missing, no focus states |
| Performance | PageSpeed targets met | Unoptimised images, blocking scripts |
| Mobile | Tested across breakpoints | Only tested in DevTools |
| Forms | Submission + delivery tested | Form submits but email never arrives |

### Phase 8: SEO

| Check | Standard | Common Failure |
|-------|----------|---------------|
| Title uniqueness | Every page unique | Same title on all pages |
| Title length | 55–60 chars | 80+ chars, or 20 chars |
| Meta desc | Unique, 150–155 chars, CTA | Missing, or same on all pages |
| Schema | Valid, specific type | Generic LocalBusiness when Restaurant available |
| Local SEO | NAP consistent everywhere | Different phone formats across pages |
| Heading structure | Logical H1→H2→H3 | Multiple H1s, skipped levels |

### Phase 9: CRO

| Check | Standard | Common Failure |
|-------|----------|---------------|
| 3-second test | Passes on every page | Unclear value proposition above fold |
| CTA visibility | Visible without scrolling | CTA below the fold on homepage |
| Trust signals | Specific, real, prominent | Generic "award-winning" |
| Mobile conversion | Phone visible above fold | Contact only on contact page |
| Form friction | 5 fields or fewer | 12-field contact form |

### Phases 10–11: Performance & QA

| Check | Standard | Common Failure |
|-------|----------|---------------|
| PageSpeed mobile | ≥ 85 | 45–60 (common on image-heavy sites) |
| Core Web Vitals | All green | LCP failing on hero images |
| Zero placeholders | None anywhere | Missed copy placeholder in footer |
| All forms work | Tested on production | Works on staging, fails on production |
| Cross-browser | Tested in Safari | Only tested in Chrome |
| Console errors | Zero | Google Maps errors, font errors |

## THE ANTI-GENERIC PHRASE BLACKLIST

These phrases must never appear in any copy produced by this system:

### Overused Openers
- "Welcome to [Business Name]"
- "We are passionate about..."
- "We are dedicated to..."
- "At [Business Name], we believe..."
- "Your journey begins here"
- "Your [X] journey starts here"

### Meaningless Claims
- "World-class" (without evidence)
- "Award-winning" (without naming the award)
- "Industry-leading"
- "Best-in-class"
- "Second to none"
- "Unrivalled"
- "Unparalleled"
- "The finest"
- "Premium quality"
- "Superior"

### Generic Descriptors
- "Warm and welcoming atmosphere"
- "A home away from home"
- "Fresh, locally sourced ingredients" (without specifics)
- "Hidden gem"
- "Family-run" (as differentiator alone, without what it means)
- "State-of-the-art"
- "Cutting-edge"
- "Innovative"

### Filler Phrases
- "In today's fast-paced world..."
- "Now more than ever..."
- "More than just a [X]..."
- "At the heart of everything we do..."
- "We pride ourselves on..."
- "Our commitment to..."
- "We go above and beyond..."
- "With years of experience..."
- "We offer a wide range of..."
- "Quality you can trust"

### Weak CTAs
- "Click here"
- "Learn more"
- "Read more"
- "Find out more"
- "Get in touch" (without specificity)
- "Contact us today"
- "Submit"

## THE NON-GENERIC DESIGN CHECKLIST

Before any design is approved, confirm:

- [ ] The colour palette is NOT: generic blue, standard green, or "website grey"
- [ ] The typography is NOT: the same as every other local business site (Arial, generic sans-serif)
- [ ] The hero section is NOT: a full-width image with white text centred — unless it's genuinely stunning
- [ ] The layout is NOT: the same column structure as every WordPress theme from 2018
- [ ] The cards are NOT: generic equal-height boxes with icon, title, description on loop
- [ ] The footer is NOT: a 4-column grid of links with a copyright notice
- [ ] The homepage does NOT: begin with "Welcome to [Business Name]"
- [ ] The overall feel does NOT: look like a $29 ThemeForest template

**If any box CANNOT be checked, the design needs to be reconsidered.**

## QUALITY ESCALATION PROCESS

1. Agent submits output
2. Orchestrator reviews against quality gates
3. If output fails: Orchestrator returns with **specific** revision instructions
4. Agent revises and resubmits (v2)
5. If v2 still fails: Orchestrator identifies root cause (unclear brief? wrong input?)
6. If 3+ revision rounds: Orchestrator escalates to user with specific question
7. Never approve mediocre work because it's faster

---

## QUALITY SIGN-OFF AUTHORITY

- **Orchestrator Agent** signs off on all phase outputs
- **Only the Orchestrator** can approve movement to the next phase
- No sub-agent can self-approve their own work
- Client approval is required before launch (not optional)
