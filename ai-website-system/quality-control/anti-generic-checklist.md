# Anti-Generic Checklist

> Run this checklist when reviewing any website output — copy, design, or strategy.
> A single YES on any "Is it generic?" question = revision required.

## SECTION 1: COPY ANTI-GENERIC TEST

For each piece of copy, answer YES or NO:

| # | Question | Answer | Action if YES |
|---|----------|--------|---------------|
| 1.1 | Could this headline appear on any competitor's website? | Y/N | Rewrite with client-specific detail |
| 1.2 | Does this copy contain any phrase from the blacklist? | Y/N | Remove and rewrite |
| 1.3 | Does the copy describe the business rather than the customer benefit? | Y/N | Flip perspective |
| 1.4 | Is there any claim without specific evidence? | Y/N | Add evidence or remove claim |
| 1.5 | Does any CTA just say "Book Now", "Contact Us", or "Learn More"? | Y/N | Make it specific |
| 1.6 | Does any section contain filler that could be removed without losing meaning? | Y/N | Cut or rewrite |
| 1.7 | Does the copy sound like it was written by AI? | Y/N | Rewrite with human voice and specifics |
| 1.8 | Is the tone generic (not matching the brand voice doc)? | Y/N | Align to tone of voice document |

---

## SECTION 2: DESIGN ANTI-GENERIC TEST

| # | Question | Answer | Action if YES |
|---|----------|--------|---------------|
| 2.1 | Does the colour palette look like a default website? | Y/N | Revisit with brand strategy in mind |
| 2.2 | Does the typography look like it came with a theme? | Y/N | Make deliberate, brand-justified font choice |
| 2.3 | Is the layout interchangeable with any competitor's site? | Y/N | Rethink layout with brand differentiation in mind |
| 2.4 | Are there generic stock photos (posed, obviously stock)? | Y/N | Replace with real photos or art-directed selections |
| 2.5 | Are there generic icons that feel lifted from a UI kit? | Y/N | Use specific, consistent icon approach |
| 2.6 | Does the homepage hero look like every other website in the category? | Y/N | Differentiate — different structure, different visual approach |
| 2.7 | Is there anything decorative that serves no strategic purpose? | Y/N | Remove decorative-only elements |

---

## SECTION 3: STRATEGY ANTI-GENERIC TEST

| # | Question | Answer | Action if YES |
|---|----------|--------|---------------|
| 3.1 | Is the brand positioning something any competitor could claim? | Y/N | Find the real differentiator and reposition |
| 3.2 | Do the brand pillars feel like they belong to every business? | Y/N | Make pillars specific to this business |
| 3.3 | Is the audience description too vague to be useful? | Y/N | Add specificity until you can picture a real person |
| 3.4 | Do the key messages match what the audience wants (not just what client wants to say)? | Y/N | Rewrite from audience perspective |
| 3.5 | Is the tone of voice description too vague to guide copywriting? | Y/N | Add concrete examples ("instead of X, say Y") |
