# Phase 6 — Visual Direction

## Objective
Define the complete visual system for the website — colours, typography, spacing, imagery direction, component visual specs, and interaction design. Leave zero visual decisions to the developer.

## Responsible Agent
UI Design Agent (`/agents/05-ui-design-agent.md`) — Phase 6 mode
Skill to load: `premium-website-design-skill.md` | `hospitality-website-skill.md` (if applicable)

## Required Input
- Approved Wireframe Logic
- Approved Brand Strategy
- Approved Page Copy
- Any existing brand assets (logo, existing colours)
- Reference websites from brief

## Process

1. Orchestrator briefs UI Design Agent in Phase 6 (visual direction) mode
2. UI Design Agent develops the design concept grounded in brand strategy
3. UI Design Agent defines the complete style system
4. UI Design Agent specifies every component visually
5. Orchestrator reviews: Are all values specific? Does it match brand tone? Does it differentiate?
6. If approved → version and save.

## Expected Output

File: `[client-slug]-visual-direction-v1.md`
Saved to: `client-projects/[client-slug]/05-design/`

Contents:
- Design concept + rationale
- Colour palette (all hex values + usage)
- Typography (fonts + full scale for desktop + mobile)
- Spacing system
- Imagery direction
- Button styles (primary + secondary)
- Component visual specs (all components)
- Animation + interaction guidelines
- What the design must NOT do

## Quality Gate

Do NOT approve and move to Phase 7 unless:
- [ ] All colours given as specific hex values
- [ ] Typography scale is complete for desktop AND mobile
- [ ] Every component from the wireframe has a visual spec
- [ ] Design rationale documented for key decisions
- [ ] Differentiates visually from competitor references
- [ ] Developer could build without asking any visual question
- [ ] Visual direction matches brand tone of voice (words and visuals aligned)
