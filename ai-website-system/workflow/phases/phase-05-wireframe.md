# Phase 5 — Wireframe Logic

## Objective
Define the layout structure and component architecture of the website. Map every section on every page and specify which components are needed. Give the developer a complete layout blueprint before any visual decisions are made.

## Responsible Agent
UI Design Agent (`/agents/05-ui-design-agent.md`) — Phase 5 mode

## Required Input
- Approved Client Brief
- Approved Brand Strategy
- Approved Sitemap + Content Hierarchy
- Approved Page Copy

## Process

1. Orchestrator briefs UI Design Agent in Phase 5 (wireframe) mode
2. UI Design Agent maps components needed across all pages
3. UI Design Agent creates section-by-section layout for each page
4. UI Design Agent specifies navigation structure
5. UI Design Agent documents conversion flow logic
6. Orchestrator reviews for completeness and conversion logic
7. If approved → version and save.

## Expected Output

File: `[client-slug]-wireframe-logic-v1.md`
Saved to: `client-projects/[client-slug]/05-design/`

Contents:
- Component library (all components needed)
- Page-by-page section layout (top to bottom)
- Navigation specification (desktop + mobile)
- Conversion flow notes per page
- Mobile behaviour of each section

## Quality Gate

Do NOT approve and move to Phase 6 unless:
- [ ] Every component is listed and named
- [ ] Every page has a complete section-by-section layout
- [ ] Navigation specified for desktop AND mobile
- [ ] Conversion flow logic documented for each page
- [ ] Mobile behaviour defined for key sections
- [ ] Developer could build the structure without making layout decisions
