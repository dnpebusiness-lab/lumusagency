# Phase 12 — Post-Launch Improvement

## Objective
Monitor the live website, gather data, and make data-driven improvements that increase conversions, improve rankings, and maintain technical quality over time.

## Responsible Agent
Maintenance Agent (`/agents/12-maintenance-agent.md`)

## Timeline

### Week 1 post-launch
- Monitor for any technical issues
- Check analytics is collecting data correctly
- Verify Google Business Profile is active
- Confirm all contact methods are working
- Address any issues from real users

### Month 1 report
- First full monthly report
- Review GA4 data: which pages are performing, which are not
- Review Search Console: any impressions and clicks appearing
- Identify any quick-win improvements based on real data

### Month 3 review
- First meaningful SEO data available
- CRO review based on real user behaviour
- Content refresh opportunities identified
- Technical health check

### Ongoing (monthly)
- Monthly report produced
- Improvement backlog maintained and prioritised
- Google Business Profile kept active
- Security and dependency updates applied

## Expected Output

- Monthly report: `[client-slug]-monthly-report-[YYYY-MM].md`
- Improvement backlog: `[client-slug]-improvement-backlog.md`
Saved to: `client-projects/[client-slug]/11-maintenance/`

## Key Metrics to Track

| Metric | Target |
|--------|--------|
| Monthly organic sessions | Growing month-on-month |
| Contact form conversions | Track conversion rate |
| Google ranking for primary keyword | Top 3 locally |
| PageSpeed mobile | ≥85 maintained |
| Core Web Vitals | All green |
| Bounce rate | < 60% |

## Post-Launch Improvement Opportunities

Common wins found in first 3 months:
- New testimonials added (trust signal boost)
- FAQ section added based on real customer questions
- Blog post targeting a high-intent local keyword
- Improved hero copy based on heatmap / user data
- Additional page for a specific service getting search traction
- Google Business Profile optimisation
- Schema markup additions (FAQPage, Event, Offer)
